## 対象者

本人の結婚、または家族の不幸などで休暇を取る社員。

弔事の休暇は「忌引き」とも呼ばれます。

## 必要なもの

- 勤怠システムのアカウント
- 事実がわかる書類（会葬礼状、結婚式の案内状など。後日提出で可）

## 手順

1. まず上長に口頭または電話で連絡する
2. 勤怠システムの「休暇申請」で、休暇の種類に「慶弔休暇」を選ぶ
3. 事由（結婚、弔事など）と日数を入力して申請する
4. 休暇明けに、事実がわかる書類を人事部に提出する

## 日数の目安

| 事由 | 日数 |
| --- | --- |
| 本人の結婚 | 5日 |
| 配偶者・父母・子の弔事 | 5日 |
| 祖父母・兄弟姉妹の弔事 | 2日 |

## 注意点

- 会社からの弔慰金や供花の手配は、人事部が行います。申請の際に、式の日時と場所がわかれば伝えてください
- 日数は土日祝日を含まずに数えます
