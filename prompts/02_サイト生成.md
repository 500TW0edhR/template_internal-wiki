社内ナレッジサイトを作ってください。私はエンジニアではないので、専門用語は使わず、作業は代わりに実行してください。

## これは何か
社内の業務マニュアルを集めて、検索して探せるようにする社内向けのサイトです。
最終的にインターネット上に公開します。

## 使う材料
- docs/ にあるマニュアル（これが原本です。中身は変えないでください）
- design.md（カテゴリとタグの設計。ない場合は docs/ の category をそのまま使う）

## 技術的な条件
- HTML・CSS・JavaScript だけで作る。Node.js やビルドツールは使わない
- index.html をダブルクリックしてブラウザで開けば、そのまま動く状態にする
- 検索は外部サービスを使わず、ページ内のJavaScriptで完結させる
- スマホでも見やすくする（現場でスマホから調べる想定）

## 作るもの
- index.html（トップ）
- pages/ の中に、マニュアル1本につき1つのHTML（ファイル名は docs/ と同じ名前で、拡張子だけ .html）
- search-index.json（検索用のデータ。形は下のとおり）
- style.css
- CLAUDE.md（今後の作業ルール）

## search-index.json の形
次の形の一覧にしてください。マニュアル1本につき1件です。

[
  {
    "title": "経費精算の手順",
    "category": "経理",
    "tags": ["経費", "精算", "申請"],
    "updated": "2026-09-01",
    "owner": "経理部",
    "url": "pages/経費精算の手順.html",
    "text": "本文から見出しや記号を除いた文章"
  }
]

index.html をダブルクリックで開いたときにも検索が動くよう、search-index.json と同じ内容を JavaScript のファイル（search-index.js）にも書き出し、index.html はそちらを読み込むようにしてください。

## 画面
1. トップ（index.html）
   - サイト名と、1行の説明
   - 検索窓：入力するたびに絞り込む（タイトル・本文・タグが対象）
   - 検索結果：タイトル、本文の冒頭2行、タグを表示
   - 検索していないときは、カテゴリ別の一覧を表示
2. マニュアル本文（pages/ の中）
   - タイトル、管理部署、更新日
   - 本文
   - トップに戻るリンク

## デザイン
- 白背景、装飾は最小限、文字は読みやすい大きさ
- 検索窓を画面の中心に置く（探すことが主目的のため）
- 派手な色は使わず、リンクや強調にだけ色を使う

## CLAUDE.md に書いておくこと
- このサイトの目的と構成
- docs/ が原本であり、pages/、search-index.json、search-index.js は生成物であること
- マニュアルを追加・更新したら、必ず pages/、search-index.json、search-index.js を作り直すこと
- 私がエンジニアではないこと（専門用語を避け、作業後は何をしたか3行で報告する）
